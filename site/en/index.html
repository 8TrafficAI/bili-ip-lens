Install the ZIP build

  1. Download and extract bili-ip-lens-0.1.1.zip into a permanent folder.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose “Load unpacked” and select the extracted folder containing manifest.json. If using the source repository, select its extension/ directory instead.
  4. Pin Bili IP Lens, refresh an open Bilibili page, and scroll to the comments.
  5. Use the toolbar popup to toggle region labels. Future toggles do not need a refresh.

What is supported?

The extension targets Bilibili’s current Lit comment component, including main comments and nested replies. Video comments and the real toolbar popup were tested locally in ego-browser. Dynamic and profile comments can work when they use the same component, but have not been manually checked across all scenarios.

Chrome / Chromium 111+ is required by the manifest. Other browser profiles need their own installation and verification.

What it does not do

It does not reveal full IP addresses, infer precise location, supply missing region data, or show regions for real-time livestream chat. Historical Vue comment components are outside the current scope. It contains no Super Chat overlay feature.

Where does the data come from?

Bilibili already includes a region string in some comment data. Bili IP Lens renders that existing string; it makes no IP lookup or backend request. Comments without that field remain unchanged.
