Bili IP Lens/安装/AI 安装

Agent Skills · 2026-11-17

给 AI 一份说明，
把安装做到验证。

Bili IP Lens 提供可安装的 Agent Skill。让具备相应浏览器工具的 AI，优先从已上架的 Chrome Web Store 正常安装并验证；需要 ZIP 高级备用时，再校验公开发行包和准备本地文件。

一条命令装好的是技能，不是自动启用浏览器扩展。

浏览器必要的确认仍需按正常流程完成。v0.1.1 已于 2026-11-17 确认在 Chrome Web Store 公开上架；此教程优先使用商店正常安装，GitHub Release 为高级备用。它不承诺完全无人值守，也不代表任何 AI Marketplace 已经收录。

先看你的 AI 能做什么

普通 ChatGPT、Gemini 网页聊天可以阅读本页并解释步骤，但阅读说明不会让它获得操作你电脑的能力。只有当前会话提供本机终端、文件或浏览器工具，并允许完成这项安装时，Agent 才能执行相应操作。

Codex、WorkBuddy 等产品也应以当前会话实际可用的工具为准。若 Agent 不支持 Skills CLI 的安装目标，可以把本页与技能源码交给它阅读；没有执行工具时，使用手动安装指南。

第一步：安装 Agent Skill

在准备使用的项目中运行：

npx skills add 8TrafficAI/bili-ip-lens --skill bili-ip-lens

这是 Skills CLI 官方支持的 GitHub 仓库语法。按 CLI 提示选择目标 Agent；默认安装到当前项目。当前 CLI 需要 Node.js 22.20+，可选 -g 安装为用户级技能。CLI 有其自身的遥测政策，与 Bili IP Lens 扩展运行时无使用追踪是两回事。

无法读取 GitHub 正文？

可让 Agent 直接读取本站的纯文本 SKILL.md，以及相对路径下的下载校验助手和验证说明。这些是仓库中同一份技能的静态副本，CI 会检查字节一致；读取说明不会自动执行脚本。

如果聊天工具丢失链接地址，可复制下面的完整 URL：

第二步：给 AI 一句话

安装 Bili IP Lens 并验证 IP 属地开关。

同时说明要使用的浏览器。已经安装扩展时，让它核对版本和状态，避免重复装扩展版与油猴版。技能的目标是完成安装验证；它不会让普通聊天或没有工具的会话自动变成电脑操作 Agent。

AI 会按哪条路径完成？

  1. 核对真实分发入口

    先读取项目当前安装说明，再打开 已上架的项目 Chrome Web Store 页面，核对名称、版本及项目网站后，通过安装按钮和正常浏览器确认完成安装。商店安装不需要运行 ZIP 助手。

  2. 仅 ZIP 高级备用：校验并准备文件

    仅在用户选择 ZIP 或商店路径不可用时，macOS/Linux 助手从固定项目仓库读取最新公开 Release，下载版本匹配的 ZIP 和 SHA256SUMS.txt，核对 SHA-256，检查归档路径、文件类型、manifest 身份、版本和权限范围。它不需要 GitHub Token 或管理员权限，也不运行下载的远程 Shell。

  3. 确认扩展已加载

    商店安装后，在浏览器扩展管理页核对名称、版本与启用状态。仅 ZIP 备用方式使用助手输出的 install_path（默认 ~/.local/share/bili-ip-lens/extension）并通过「加载已解压的扩展程序」加载。Agent 不会扫描浏览器 profile、读取 Cookie、改写 Chrome Preferences 或绕过确认。

  4. 验证实际效果

    刷新 B站页面，检查带地区字段的现代主评论和楼中楼；打开真正的工具栏弹窗，关闭后确认标签消失，再开启确认恢复。重新打开弹窗，检查设置是否保留。评论没有地区字段时保持空白，不能猜一个属地填上。

怎样知道做到哪一步了？

状态实际含义
技能已安装Agent 能发现这份工作说明；浏览器尚未因此改变。
文件已准备仅 ZIP 备用路径：发行包校验完成并输出安装路径；扩展仍可能尚未加载。
扩展已加载浏览器扩展管理页显示正确名称和版本。
功能已验证实际评论与弹窗的 OFF / ON、重新打开后的状态均已检查。

让 Agent 报告实际版本、浏览器、安装路径、验证了哪些页面，以及还需要你处理的步骤。不要把文件准备成功当成浏览器已经安装成功。

高级备用：只想先检查 ZIP 文件？

在已安装的 bili-ip-lens 技能目录运行：

bash scripts/install-extension.sh --dry-run

需要 curl 和 Python 3.8+。这会在临时目录下载、校验并检查发行包，不创建或更改目标安装目录。确认要准备文件时，移除 --dry-run 运行同一个助手。

助手使用 POSIX 文件锁与安全文件打开方式，支持 macOS/Linux；Windows 用户走手动 ZIP 安装。校验失败或现有扩展目录含无关／修改过的文件时，它会停止，不删除这些内容，也不操作浏览器配置。

如果只想用油猴版

用户脚本已在 Greasy Fork 发布，也保留 GitHub 源码入口。告诉 Agent 你选择的是用户脚本，不要再跑扩展安装助手。油猴版通过脚本管理器的 Bili IP Lens 菜单切换，没有独立 Chrome 弹窗。

范围、隐私与来源

Bili IP Lens 只显示 B站现代评论已经提供的地区字符串，不查询完整 IP，不推断精确位置，不支持实时直播弹幕属地或历史 Vue 评论组件。当前扩展浏览器验收在 ego-browser 完成，其他浏览器与用户脚本管理器仍需各自验证。

现代评论接入改编自 MaxChang3/BiliReveal，保留完整 MIT 署名。查看隐私说明、兼容范围与常见问题和完整技能及助手源码。公开说明和技能安装命令有助于读者或 Agent 找到事实，不保证搜索、推荐或 Marketplace 收录。
