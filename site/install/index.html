Bili IP Lens/安装指南

开始使用 · v0.1.1

B站 IP 属地插件
怎么安装？

目前可以下载 ZIP 后加载到 Chrome / Chromium 浏览器。首次安装完成后，刷新已经打开的 B站页面。

Chrome Web Store 上架准备中。

此页提供的是开源版本本地安装步骤。请按下方说明，在扩展管理页开启开发者模式并加载解压后的文件夹。

方法一：下载扩展 ZIP

  1. 下载发布包

    下载 bili-ip-lens-0.1.1.zip，或到 GitHub Releases 核对版本和校验和。

  2. 解压到固定目录

    将 ZIP 解压。打开后应该能直接看见 manifest.json、popup.html 等文件。加载后请保留这个文件夹。

  3. 打开扩展管理页

    在浏览器地址栏输入 chrome://extensions，打开右上角「开发者模式」。

  4. 加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择刚才解压后、包含 manifest.json 的文件夹。不要选择 ZIP 文件本身。

  5. 固定图标并刷新 B站

    在工具栏扩展菜单里固定 Bili IP Lens。刷新 B站视频页面并滚动到评论区，点击图标，用「显示 IP 属地」开关控制展示。

方法二：从源码加载

如果你克隆或下载的是整个 GitHub 仓库，加载时选择仓库里的 extension/ 子目录。这与发布 ZIP 解压目录不同：仓库根目录不直接包含扩展 manifest。

git clone https://github.com/8TrafficAI/bili-ip-lens.git
# 在扩展管理页选择 bili-ip-lens/extension

查看 Chrome 官方加载本地扩展说明，可以核对这套安装流程。

方法三：油猴用户脚本

已安装 Tampermonkey 等用户脚本管理器的用户，可以打开 Bili IP Lens 用户脚本，检查脚本名称、匹配的 B站域名和源码后，再在管理器中安装。没有管理器时，浏览器可能只会展示脚本文本。

Greasy Fork 发布正在准备中，实际可用链接会在确认发布后补充。用户脚本的开关入口以脚本管理器菜单中的说明为准；Chrome 扩展版使用工具栏弹窗开关。

怎么关闭、更新或卸载？

  • 临时隐藏：点击工具栏图标，关闭「显示 IP 属地」。不需要刷新，之后仍可恢复。
  • 更新本地扩展：用新版本文件更新固定目录，在扩展管理页点「重新加载」，再刷新 B站页面。
  • 卸载：在扩展管理页点「移除」，浏览器会删除扩展的本地设置；刷新 B站页面可清理已经显示的标签。

装好却没有显示？

先刷新 B站页面，再展开评论区，确认开关已开启。部分历史评论没有地区字段，新版组件之外的评论区也可能不支持。阅读常见问题与兼容范围，或在 GitHub Issues 提供页面类型、浏览器版本和复现步骤。
