Bili IP Lens/安装指南

开始使用 · v0.1.1

B站 IP 属地插件
怎么安装？

推荐从已上架的 Chrome Web Store 正常安装；ZIP 和源码保留为高级备用方式。首次安装完成后，刷新已经打开的 B站页面。

v0.1.1 已公开上架 Chrome Web Store。

2026-11-17 已核对公开商店页面。前往商店安装，无需下载 ZIP 或开启开发者模式；下方仍保留高级备用步骤。

推荐：Chrome Web Store 安装

  1. 核对项目商店页面

    打开 Bili IP Lens 商店页面，核对名称「Bili IP Lens · B站评论 IP 属地」以及项目网站。

  2. 按浏览器提示安装

    点击商店安装按钮，完成浏览器正常确认，再将 Bili IP Lens 固定到工具栏。

  3. 刷新并验证开关

    刷新已打开的 B站视频页，选择带地区字段的最新评论，关闭并开启弹窗开关，确认标签即时隐藏与恢复。

高级备用：下载扩展 ZIP

  1. 下载发布包

    下载 bili-ip-lens-0.1.1.zip，或到 GitHub Releases 核对版本和校验和。

  2. 解压到固定目录

    将 ZIP 解压。打开后应该能直接看见 manifest.json、popup.html 等文件。加载后请保留这个文件夹。

  3. 打开扩展管理页

    在浏览器地址栏输入 chrome://extensions，打开右上角「开发者模式」。

  4. 加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择刚才解压后、包含 manifest.json 的文件夹。不要选择 ZIP 文件本身。

  5. 固定图标并刷新 B站

    在工具栏扩展菜单里固定 Bili IP Lens。刷新 B站视频页面并滚动到评论区，点击图标，用「显示 IP 属地」开关控制展示。

高级备用：从源码加载

如果你克隆或下载的是整个 GitHub 仓库，加载时选择仓库里的 extension/ 子目录。这与发布 ZIP 解压目录不同：仓库根目录不直接包含扩展 manifest。

git clone https://github.com/8TrafficAI/bili-ip-lens.git
# 在扩展管理页选择 bili-ip-lens/extension

查看 Chrome 官方加载本地扩展说明，可以核对这套安装流程。

替代方式：油猴用户脚本

用户脚本已在 Greasy Fork 发布。已安装 Tampermonkey 等管理器的用户，可打开页面并点击「安装此脚本」，核对名称与匹配域名后完成安装。也可使用 GitHub 源码备用入口；没有管理器时，浏览器可能只会显示文本。

从脚本管理器的 Bili IP Lens 菜单切换显示；它没有独立 Chrome 弹窗。Chrome 扩展版和油猴版建议二选一。Chrome 商店版与 Greasy Fork 用户脚本是独立分发入口，请选择一种安装。

安装后确认管理器全局为 Enabled、脚本已启用，并在浏览器扩展详情中检查正常的「允许运行用户脚本 / Allow User Scripts」许可。首次安装后刷新 B站页面；部分旧热评没有地区字段，不会补填属地。本次实测中的浏览器许可原本已开启，无需更改。

发布版 0.1.1 已在 ego-browser + Tampermonkey 5.5.1 的单个视频最新评论列表独立验证：18 条带地区评论全部显示匹配标签，菜单 OFF 清空本脚本标签、ON 恢复 18 条，重开菜单保留开关状态。其他管理器、动态或空间页仍需分别验收。查看验证记录。

让 AI Agent 协助安装

给支持 Agent Skills 的编码 Agent 安装 bili-ip-lens 技能，再告诉它「安装 Bili IP Lens 并验证 IP 属地开关」。它可以在具备本机工具时协助校验文件、正常加载和验证；浏览器必要确认仍需完成。阅读完整 AI 安装教程与适用范围。

怎么关闭、更新或卸载？

  • 临时隐藏：点击工具栏图标，关闭「显示 IP 属地」。不需要刷新，之后仍可恢复。
  • 商店版更新：通过浏览器的 Chrome Web Store 更新流程更新；更新后刷新已打开的 B站页面。
  • 更新本地扩展：用新版本文件更新固定目录，在扩展管理页点「重新加载」，再刷新 B站页面。
  • 卸载：在扩展管理页点「移除」，浏览器会删除扩展的本地设置；刷新 B站页面可清理已经显示的标签。

装好却没有显示？

先刷新 B站页面，再展开评论区，确认开关已开启。部分历史评论没有地区字段，新版组件之外的评论区也可能不支持。打开属地排查页按症状检查，或阅读常见问题与兼容范围，或在 GitHub Issues 提供页面类型、浏览器版本和复现步骤。
