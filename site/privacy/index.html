Bili IP Lens/隐私

2026-11-15 更新

信息留在页面里。

Bili IP Lens 只在本机显示 B站已提供的评论 IP 属地。我们没有接收评论、地区或使用记录的服务器。

扩展保存什么？

只在浏览器扩展本地存储中保存 enabled 布尔开关。移除扩展会删除这项设置。

用户脚本版保存什么？

油猴用户脚本将 bili-ip-lens-enabled 布尔开关保存在用户脚本管理器本地，通过管理器菜单控制显示。支持对应 GM API 的管理器可以把设置变化同步到已经打开的标签页。地区文字仍留在页面内处理。

页面里处理什么？

读取新版 B站评论组件已有的地区字段，在发布时间旁添加文字标签。评论内容和地区字段不会发送给开发者或第三方；工具栏与弹窗只读取本地开关。

权限用于什么？

扩展仅声明 storage 权限保存设置。静态内容脚本仅匹配 www.bilibili.com、t.bilibili.com、space.bilibili.com，以接入这些页面的新版评论组件。

没有哪些行为？

  • 没有第三方 IP 查询、数据上传、使用统计或广告服务。
  • 没有处理完整 IP 地址、精确定位、账户密码或直播弹幕位置。
  • 没有遥测、远程脚本或后台服务器请求。

这个产品网站呢？

此站为静态页面，不包含第三方分析或广告脚本。站点由 GitHub Pages 托管，访问时托管服务会按照它自身的政策处理网络请求。下载按钮和源码链接会跳转 GitHub；这些平台有各自的隐私政策。

如何联系或核对？

可以直接审阅公开源码、仓库隐私说明，或通过 GitHub Issues 反馈。请勿在公开问题中提交密码、Cookie、完整浏览记录或其他私人资料。

本扩展与哔哩哔哩没有官方隶属关系。B站可能改变其数据和组件，影响展示可用性。
