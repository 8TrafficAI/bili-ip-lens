Bili IP Lens/属地排查

B站评论看不到
IP 属地？

电脑网页版的评论有时带着地区数据，但页面没有显示。先看你遇到的是哪种情况，再决定要不要安装工具。

电脑网页版想开启属地显示

在 Chrome 商店安装 Bili IP Lens，刷新已经打开的 B站视频页。展开评论区，在扩展弹窗里开启「显示 IP 属地」，地区会出现在带数据的评论时间旁。

已经安装，所有评论还是空白
  1. 在浏览器扩展管理页确认 Bili IP Lens 已启用，再打开工具栏弹窗确认「显示 IP 属地」已开启。
  2. 如果用油猴版，在管理器中启用脚本，并核对 Bili IP Lens 菜单的开关。
  3. 刷新 B站视频页，切换到最新评论，再展开一条回复。用右侧视频做一次对照。

对照视频也看不到时，可以附上浏览器版本和页面类型反馈。报告问题

有些评论显示，有些没有

属地取决于 B站为每条评论提供的地区字段。旧评论或缺少地区字段的评论会留白。若同页其他评论已有标签，先切到「最新」比较几条，再用工具栏开关确认标签能隐藏和恢复。

想在手机、直播弹幕里看属地

Bili IP Lens 面向桌面浏览器里的新版 B站评论，支持已验证的视频主评论和楼中楼。手机 App 和直播实时弹幕超出当前支持范围。
