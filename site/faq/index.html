关于评论 IP 属地，
你想知道的。

以当前 v0.1.1 的实际实现和本地验证为准。最后更新：2026-11-15。

Bili IP Lens 是什么？

Bili IP Lens 是免费的开源 Chrome / Chromium 扩展，在 B站新版评论的发布时间旁显示平台已经提供的 IP 属地。工具栏弹窗中的开关可以即时显示或隐藏标签，设置保存在浏览器本地。

B站网页版为什么有些评论看不到 IP 属地？

本插件只读取评论组件已经带有的地区数据。部分历史评论没有地区字段；旧版 Vue 评论区也不在 v0.1.1 的支持范围内。缺失数据时，插件保持原样，不自行猜测地区。

IP 属地信息从哪里来？能看到完整 IP 吗？

信息来自 B站评论组件的 reply_control.location 地区字段。它是平台提供的地区字符串，不是完整 IP 地址。Bili IP Lens 不额外查询 IP，不定位用户，也不推断精确位置。

支持哪些浏览器和页面？

扩展 manifest 要求 Chrome / Chromium 111 及以上。当前已在 ego-browser 的新版视频主评论、楼中楼和工具栏弹窗完成本地验证。Chrome 及其他 Chromium 浏览器、动态和空间评论仍需按实际页面测试；后两者使用同一新版组件时适用。

能显示直播实时弹幕的属地吗？

不能。v0.1.1 只接入新版评论组件，不提供直播实时弹幕属地。它也不会给直播画面添加 Super Chat 卡片。其他扩展已经添加的 SC 卡片，需要在那个扩展中关闭相应功能或停用。

怎么安装？安装后需要刷新吗？

目前可以下载 ZIP并解压，在 chrome://extensions 中开启开发者模式后加载含 manifest.json 的文件夹。首次安装、重新加载或更新扩展后，刷新已打开的 B站页面。详见安装指南。

怎样一键隐藏或恢复 IP 属地？

点击工具栏里的 Bili IP Lens 图标，使用「显示 IP 属地」开关。已加载评论中的本插件标签会立即隐藏或恢复。关闭再打开弹窗，或者刷新页面，仍会保留已保存的开关状态。

和 BiliReveal、B站助手有什么区别？

新版评论接入代码改编自 BiliReveal，原作者是 MaxChang3，本项目保留其 MIT 版权与许可。Bili IP Lens 以独立 MV3 扩展提供评论属地、工具栏状态和即时开关。B站助手还提供全屏 SC 等功能；本插件不包含这些附加功能。查看来源与修改说明。

需要什么权限？会上传评论或浏览数据吗？

扩展仅声明 storage 权限保存一个布尔开关；内容脚本匹配 www.bilibili.com、t.bilibili.com、space.bilibili.com 三个域名。没有服务器、分析统计、远程脚本、数据上传或第三方 IP 查询。阅读完整隐私说明。

已经上架 Chrome 商店或 Greasy Fork 了吗？

油猴用户脚本已在 Greasy Fork 发布。扩展可通过 GitHub 发行版安装；Chrome Web Store 的 v0.1.1 已提交审核，目前待审核，尚未上架。也可阅读 AI Agent 安装教程。

这是 B站官方插件吗？付费吗？

不是官方插件，与哔哩哔哩没有官方隶属关系。Bili IP Lens 免费使用，源码采用 MIT License；上游版权和许可声明保留在仓库中。
